Close the month in PayPal, line by line.

closebook reads what PayPal actually did through Transaction Search and matches it against your books. Claude proposes an entry for every line that doesn't match. Code checks each one to the cent, and nothing is posted until you approve it.

  1. Rules matchBy reference, or by amount and date when only one pairing fits. Fee entries are written by rule.
  2. Claude proposesOne journal entry per leftover line, with the items it settles and a plain explanation.
  3. Code checksNine checks: it balances, uses real accounts, fits the PayPal event codes, closes the gap to the cent.
  4. You approveEvery entry, including the rule's. Reject with a reason and Claude reads it next time.
